Сработанное —

Чтобы подсветка «новая страна / новый позывной» учитывала весь ваш журнал, загрузите его экспорт в ADIF (в HAMLOG: экспорт журнала в ADIF). Связи, проведённые в пульте, добавляются сами.

Каждая связь пишется в файл ft8_log.adi рядом с программой и отправляется по UDP в формате WSJT-X — его принимают HAMLOG-агент, Log4OM, JTAlert, GridTracker. Часы ПК должны быть точными (±0,5 с).

Для связи через микрофон ПК в меню трансивера для нужных видов работы (SSB / AM / FM / DATA) параметр …_MOD_SOURCE должен указывать на USB, а …_USB_MOD_GAIN задаёт уровень звука с ПК. …_USB_OUT_LEVEL — громкость приёма, идущая в ПК. Номера значений сверьте со страницей «MOD SOURCE» в инструкции FTX-1.
